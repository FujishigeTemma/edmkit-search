## Why edmkit-search?

<CardGrid>
  <Card title="One loop, four pieces" icon="puzzle">
    State, Neighborhood, Energy, Strategy. Snap them together — there is no framework code between
    you and the search.
  </Card>
  <Card title="Built on edmkit" icon="seti:python">
    Reuses edmkit's batched simplex projection, S-Map, cross-validation splits, and metric
    functions. Selection problems framed as EDM prediction skill come together naturally.
  </Card>
  <Card title="Parallelism is yours" icon="setting">
    Energies expose a `Plan` of independent jobs. Run them sequentially, on a thread pool, or
    however you like — the search loop does not care.
  </Card>
  <Card title="Vectorized" icon="rocket">
    States, contexts, and energies are plain ndarrays. Batches of candidates are scored in a
    single call.
  </Card>
</CardGrid>

## Quick Example

```python
import numpy as np
from concurrent.futures import ThreadPoolExecutor

from edmkit.simplex_projection import simplex_projection
from edmkit.splits import temporal_fold

from edmkit.search import energy, neighborhood, state, strategy
from edmkit.search.dataset import Dataset, Subset

# Wire data, frame the problem as next-step prediction.
data = Dataset(X=X_full, Y=Y_full)
outer = temporal_fold(len(data), train_ratio=0.8)
train = Subset(data, outer.train)

inner = temporal_fold(len(train), train_ratio=0.75)

# Energy = holdout prediction skill on the inner fold.
initial_ctx, plan = energy.holdout(
    data=train,
    fold=inner,
    predict=simplex_projection,
    metric=lambda p, o: 1.0 - mean_rho(p, o),  # lower is better
)

with ThreadPoolExecutor() as pool:
    E = parallel(initial_ctx, plan, pool)        # plan → Energy (see e2e/synthetic.py)
    N = neighborhood.forward(data.X.shape[1])    # forward selection
    step = strategy.greedy(E, N)
    initial = strategy.Frontier(
        states=state.initial(),
        contexts=initial_ctx,
        energies=np.array([float("inf")], dtype=np.float64),
    )
    trace = list(strategy.run(initial, step, max_steps=8, rng=np.random.default_rng(0)))

selected = trace[-1].states[0]
```
